双层代理链使用步骤
  • 1填写住宅 IP 的 SOCKS5 信息，点击「生成融合配置（双层链）」
  • 2下载 YAML，拖入 Clash Verge 配置页完成导入
  • 3切换到该配置，确认「代理」页有 claude-chain 组（relay 类型）
  • 4Clash Verge → 设置 → 开启「虚拟网卡模式（TUN）」
  • 5直接在终端输入 claude，流量自动走：机场 → 住宅代理 → Claude ✓
验证出口 IP：curl --proxy http://127.0.0.1:7890 https://api.ipify.org，返回你的住宅 IP 即成功 ✓

  • 4直接输入 claude，流量自动走住宅 IP ✓
