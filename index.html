导入步骤
  • 1填写住宅 IP 信息，点击"生成融合配置"
  • 2点击「下载 YAML」，保存 proxy_fusion_config.yaml 到本地
  • 3打开 Clash Verge → 配置页，将 .yaml 文件拖入配置列表完成导入（需 v1.6.2+）；或点击「新建」粘贴内容保存
  • 4切换到该配置，确认 claude-chain 代理组存在
  • 5Clash Verge → 设置 → TUN 模式 → 开启（同时开启「服务模式」）
  • 6运行 Claude Code，出口 IP 即为住宅 IP ✓
验证出口 IP：在终端运行
curl -x socks5h://127.0.0.1:7891 https://api.ipify.org
返回的 IP 应为住宅 IP，而非机场 IP。
